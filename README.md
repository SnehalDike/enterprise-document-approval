# Enterprise Document Approval System

A production-style enterprise workflow platform for document review and approval using role-based access control and microservices architecture.

## Features

- JWT Authentication
- Role Based Access Control
- Bucket Management
- Document Review Workflow
- Multi-level Approval
- Audit History
- PDF Storage
- Microservices Architecture

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- PostgreSQL
- Flyway

### Frontend
- React

### DevOps
- Docker
- GitHub Actions

## Architecture

Services:

- API Gateway
- Auth Service
- User Service
- Bucket Service
- Document Service
- Workflow Service
